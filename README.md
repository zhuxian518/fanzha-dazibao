# 反诈大字报 📰 · 拦一下

> 输入爸妈正在买的东西，十秒生成一张"骗子风格"的反诈大字报——但每一条内容都是可查证的真实判决。

**在线体验**：[zhuxian518.github.io/fanzha-dazibao](https://zhuxian518.github.io/fanzha-dazibao/)

一个面向家庭反诈教育的纯前端工具：子女远程帮爸妈鉴别"量子床垫""免费领鸡蛋""稳赚不赔的养老项目"时，最难的从来不是讲道理，而是**让对方信**。这个工具把权威反诈信息翻译成爸妈最熟悉的视觉语言——街头巷尾那种高音喇叭大字报——用骗子熟悉的形式，讲反诈的实锤。

**1024 造物挑战参赛作品 · 由 WorkBuddy AI 搭档全程协作开发**

## ✨ 怎么用

1. 输入或选择爸妈正在接触的可疑东西（如"量子床垫""收藏品回收购"）
2. 引擎模糊匹配 36 个预置场景的关键词库
3. 命中 → 从真实判决/官方通报中取证据，10 秒生成一张大字报（6 套版式 × 多文案变体，可循环换风格）
4. 未命中 → 降级兜底卡：通用反诈提醒 + 自查清单，绝不编造
5. 保存图片发家庭群，或生成"自查清单"给爸妈对照

## 🧭 设计思想

**「实锤分级」是本工具的命门**：

- `data.js` 中每个场景标注 `verified`（是否经人工核验）与证据 `level`
- **只有 `verified: true` 且证据 level=1（可查证判决/官方通报）的场景才会出卡**
- 未核验场景仅显示「核验中」骨架占位——**宁可不出卡，绝不编一个案例**
- 全部未命中时降级到通用 FALLBACK 卡，仍不虚构

**「形仿神不仿」**：视觉上刻意模仿低端虚假广告的爆炸贴/神药广告/警方通告"形"（高饱和爆炸角、惊悚标题腔），但合规红线写死在代码注释里——不仿任何官方徽记与公章，"红章"是倾斜文字框，落款一律用"来源引用"措辞。

**「旧设备优先」**：目标场景是子女把生成图发到家庭群，爸妈用旧手机点开。零依赖、零网络请求、Canvas 纯本地生成，任何 WebView 都能跑。

## 🛠️ 技术栈

- **零依赖四文件**：`index.html`（入口）/ `data.js`（实锤弹药库）/ `templates.js`（6 套 Canvas 版式）/ `app.js`（匹配引擎+渲染管线）
- **Canvas 2D 生成**：750×1056 逻辑尺寸导出 @2x；避头尾换行、爆炸贴、价格爆炸标签等 9 个共用绘制原语
- **匹配引擎**：exact + fuzzy 双层关键词，命中场景后按 `verified/level` 过滤证据
- **localStorage**：仅记录生成次数，无个人信息

### 数据可信度纪律

| 字段 | 含义 |
|---|---|
| `verified: true` | 人工核验过对应判决书/官方通报原文，可出卡 |
| `verified: false` | 骨架占位（页内标「核验中」），**禁止出卡** |
| `evidence.level` | 1 = 判决/官方通报；低级别仅作参考不单独出卡 |

证据检索入口内置于页内（如国家药监局数据查询页），方便用户自行延伸核验。

## 📋 六套版式

黑金通告版 / 红色爆炸版 / 神医圣手版 / 警方提示版（不仿徽记）/ 惊爆价格版 / 兜底白卡——每版式配多文案变体，同一场景可循环换风格发家庭群而不重样。
